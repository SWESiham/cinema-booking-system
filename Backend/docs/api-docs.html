CineBook API — Cinema Ticket Booking Platform

REST backend for the React cinema-booking frontend. Node.js + Express with a JSON file database (data/db.json) instead of a real database. All data survives restarts; delete the file to reset to seed data.

v1.0.0 JSON storage Bearer auth CORS: Vite dev server allowed Base URL: http://localhost:4000
No token set — protected endpoints will return 401.

Try it: click Authorize, log in with a demo account below, then use any endpoint's Execute button. Demo accounts (password password123): admin@cinebook.com (Admin), staff@cinebook.com (Staff), emma@example.com (Customer).
Storage: backend/data/db.json — plain JSON file, auto-seeded on first run.
Frontend wiring: call http://localhost:4000/api/… from React (Vite proxy optional). Start the API with npm start inside backend/.
